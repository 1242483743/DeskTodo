# DeskTodo v1.50 · TUN 与局域网共存

保留原有卡片框架，修复开启 TUN/代理虚拟网卡后局域网搜索可能只走默认虚拟网卡的问题。

- **按网卡发现**：分别绑定各个可用 IPv4 局域网地址和 Windows 出站接口，计算真实子网广播；保留接口内有限广播兼容性并重试三轮。
- **连接路径一致**：发现回复、客户端 TCP 连接及服务端 TCP 回复使用匹配的局域网接口；同网段多网卡优先保留实际发现路径。
- **更稳健**：单个失效网卡不影响其他网卡；过滤常见 fake-IP、未连接地址及无效发现回复。仍使用原协议及管理口令，兼容旧端，建议双方更新。
- **不改系统设置**：不会关闭 TUN，不修改代理、系统路由或防火墙。如果代理严格路由阻止局域网，仍需在代理中允许局域网直连，软件不能绕过拦截策略。

包含 v1.49 的后台保存、已完成历史分页、完整数据搜索、非阻塞短提示及手动清空最近删除前备份；也包含 v1.47–v1.48 的搜索、最近删除、历史备份、移动和 TLS 更新连接改进。
