# DeskTodo v1.46

Windows 10 / 11 x64 桌面待办软件，基于 .NET Framework 4.8，MIT 开源。

## 本次更新

- 普通外观设置即时生效，连续修改合并后在后台原子保存，减少每次点击等待磁盘造成的停顿。
- 显示时间、日期及切换主题不再重建整个待办列表；透明度滑块不再重复生成主题资源。
- 缓存自启状态与副屏选项，减少普通设置操作中的重复查询。
- 完善后台保存中、失败重试、旧快照失效和窗口重建逻辑，隐藏、退出时仍检查并保存最新数据。

与上一个 GitHub 发布版 v1.22 相比，还包括新的浅深色视觉与七套主题、分组与跨组拖放、全局快捷键、可选局域网多用户管理、副屏连接自启条件，以及混合 DPI 跨屏、拖动和托盘修复。

## 下载

- `DeskTodo-Setup-v1.46.exe`：推荐安装版。
- `DeskTodo-v1.46.zip`：免安装版，完整解压并保留 `DeskTodo.exe.config`。
- `SHA256SUMS.txt`：用于核对两个下载文件的一致性。

自动生成的 `Source code` 压缩包是源码，不是运行包。新版完整源码与演示截图已同步到仓库主页。

## 升级

先导出备份，保存正在编辑的内容并退出旧版，再安装到原位置。安装器检测已有安装并保留本机待办；桌面快捷方式按安装向导中的选择处理。

默认本地保存，无需账号。局域网共享默认关闭，启用后请只在可信局域网中使用，不要将端口开放到公网。提醒需要软件运行，完全退出或关机时无法提醒。
