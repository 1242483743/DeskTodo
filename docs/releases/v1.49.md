# DeskTodo v1.49

本次重点是减少普通操作的停顿、改善历史清单加载与保存反馈，保留原有桌面卡片框架。

- 添加、完成、编辑、删除及排序改用合并后台保存；界面立即响应，后台完成序列化、校验和原子写盘。
- 隐藏、正常退出、导入及局域网修改确认仍检查实际保存结果；避免旧快照覆盖新数据。
- 已完成历史每批显示 50 条，可继续加载；搜索仍覆盖全部记录，清空确认也明确包含未加载记录。
- 导入/导出成功及检查无新版改用约 3 秒不抢焦点的短提示。
- 最近删除支持手动清空，需确认并先生成完整备份；保存失败时恢复原状态。
- 包含 v1.47 的搜索、最近删除持久化及自动历史备份，以及 v1.48 的移动闪烁、管理按钮间距和 TLS 更新连接修复。

最终应用通过 954 项检查，安装器通过 49 项检查；最终 EXE 的 HTTPS 检查更新已实测。安装器、免安装包与测试应用中的 EXE 一致。实际流畅度取决于设备和系统负载，不保证固定帧率或内存占用。

下载 `DeskTodo-Setup-v1.49.exe` 安装，或解压 `DeskTodo-v1.49.zip` 使用免安装版。升级前建议导出备份，退出旧版后再安装到原目录。保留免安装版旁边的配置文件。

Windows 10 / 11 x64，.NET Framework 4.8。软件内检查更新会提示新版本并打开发布页，不会静默下载或安装。局域网共享默认关闭，仅用于可信网络，不应映射到公网。
